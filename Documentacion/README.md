# Take Care — Documentación de Entrega (Segundo Parcial)

Paquete de documentación del vertical slice **Take Care** (Unity 6, URP). Survival horror en
primera persona.

## Índice

1. **[00_Evaluacion_Consigna.md](00_Evaluacion_Consigna.md)** — Checklist punto por punto de la
   consigna vs. el estado real del proyecto. Qué está hecho, qué falta y veredicto general.
2. **[01_GDD.md](01_GDD.md)** — Game Design Document completo: High Concept, Core Gameplay, Loop,
   Mecánicas, Mapa, Referencias, Sistemas, IA, UI, Audio, Desafío Final y Estado actual.
3. **[02_Guion_Video.md](02_Guion_Video.md)** — Guion del video (≤5 min): intro, desarrollo y cierre,
   con el texto y los roles de cada integrante (qué sistema hizo y cómo lo implementó).
4. **[03_Informe_Testing.md](03_Informe_Testing.md)** — Pruebas realizadas, bugs encontrados, ajustes,
   feedback y mejoras futuras.
